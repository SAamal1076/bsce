# 22 Oct 2026 (v31.3): three new LADMM methods, two review rounds

## New
- **LADMM options** (`bsce/models/ladmm.py`, every operator):
  - `noise_level: residual`: the noise level of the adaptive / firm / gm thresholds is the whitened residual of the
    previous layer, σ̂ = ‖W(y − A z_{t−1})‖/√M with W = (AAᵀ)^−1/2 (layer 1: the median, as before). No extra parameter.
  - `debias: ls`: after z_T, a least-squares correction on a soft support of z_T,
    x = z_T + D d, d = D Bᵀ(B D² Bᵀ + εI)⁻¹ r, D = diag(sigmoid(κ(|z_T| − τ s)/s)), B = W A, r = W(y − A z_T).
    Three parameters (κ, τ, ε ≥ 1e-4), trained in a last stage after the last layer. Python only.
- **Methods** (`run_suite.py`, workbench; not in `all`):

  | key | folder | config | setting |
  |---|---|---|---|
  | `ladmmat` | LADMM-AT | `ladmm_at.yaml` | `threshold: adaptive` (median noise level) |
  | `ladmmatr` | LADMM-ATR | `ladmm_atr.yaml` | + `noise_level: residual` |
  | `ladmmatrd` | LADMM-ATRD | `ladmm_atrd.yaml` | + `debias: ls` |

  Full operator and the training settings of `ladmm` (layer-wise); every protocol applies to them as to `ladmm`.
  ```
  python scripts/run_suite.py --scenarios sv_upa --methods ladmm ladmmat ladmmatr ladmmatrd gmlamp --protocol fair --device cuda
  ```
- Cost (SV, T = 6, MACs per channel): LADMM / LADMM-AT 0.85 M, LADMM-ATR 1.21 M, LADMM-ATRD 6.27 M (the M×M solve).

## Pilot (CPU, SV UPA, GM-LAMP's CS matrix, 2000 standard test channels, 3 seeds; small data: indicative only)
Test NMSE (dB), mean of 3 seeds (spread ≤ 0.3 dB).

T = 1, 500 training channels, 5000 iterations per stage:

| | 0 dB | 8 dB | 20 dB |
|---|---|---|---|
| LADMM | −1.11 | −6.70 | −7.60 |
| LADMM-AT | −3.40 | −7.05 | −8.21 |
| LADMM + debias | −1.55 | −7.29 | −8.35 |
| LADMM-AT + debias | −3.73 | −7.83 | −9.49 |

T = 2, 1000 training channels, 2000 iterations per stage:

| | 0 dB | 8 dB | 20 dB | train |
|---|---|---|---|---|
| LADMM | −1.94 | −8.45 | −9.73 | −14.82 |
| LADMM-AT | −5.11 | **−9.22** | **−10.63** | −14.96 |
| LADMM-ATR | −5.17 | −9.10 | −10.44 | −15.53 |
| LADMM-ATRD | **−5.24** | −9.10 | −10.58 | −16.29 |

3GPP UPA (built-in TR 38.901 generator, 1000 training / 500 validation / 2000 test channels), the same T = 2 run:

| | 0 dB | 8 dB | 20 dB | train |
|---|---|---|---|---|
| LADMM | −2.61 | −9.98 | −12.25 | −15.52 |
| LADMM-AT | **−5.54** | **−10.26** | **−12.62** | −15.03 |
| LADMM-ATR | −5.31 | −10.06 | −12.48 | −15.67 |
| LADMM-ATRD | −4.92 | −9.78 | −12.42 | −16.40 |

The noise-adaptive threshold is the robust gain (+3.2 dB at 0 dB, +0.9 dB at 20 dB at T = 2). The residual noise level
does not beat the median, on SV nor on 3GPP (−0.15 to −0.23 dB), contrary to the expectation for less sparse channels;
the debias layer adds ≈ 0.1 dB at T = 2 on SV (+0.75 dB at T = 1) and loses 0.1–0.6 dB on 3GPP, while it fits the
training channels better: with 1000 channels both extras over-fit. Their value has to be measured on the full data.
With 500 channels and T = 2 every variant over-fits (train −18.5 dB, test −7.3 dB); see the review notes.
